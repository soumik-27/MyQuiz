🧠 MyQuiz — Blockchain Quiz Results Storage

📘 Project Description

MyQuiz is a simple, beginner-friendly Solidity smart contract that stores and verifies users' quiz results on-chain. It saves each user's highest score with a timestamp so results are transparent, tamper-proof, and publicly verifiable.

This repository is ideal for newcomers learning how to write, deploy, and interact with smart contracts using Remix and MetaMask.

⚙️ What it does

Users can submit a quiz score (0–100).

The contract stores only the user's highest score.

A timestamp is recorded when the score is updated.

Anyone can query any address to verify the stored score and timestamp.

Emits events so frontends or indexers can track updates.

✨ Features

✅ Saves each user's best quiz result

✅ Publicly verifiable results (transparent & auditable)

✅ Emits ScoreSubmitted events for off-chain tracking

✅ Minimal and gas-efficient — great for learning and prototyping

✅ Easy to deploy with Remix + MetaMask
